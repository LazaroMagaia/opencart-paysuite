
# Changelog

All notable changes to PaySuite for OpenCart will be documented
in this file.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/).

- Initial release of PaySuite for OpenCart.
- OpenCart 4.x extension structure.
- Administrative extension components.
- Catalog extension components.
- PaySuite payment gateway integration.
- Initial installation package configuration.

- Added proprietary software license.
- Added changelog documentation.

### Compatibility

- OpenCart 4.x.
